# 🛒 ShopKart

A full-stack **MERN Stack E-Commerce Website** built with React, Node.js, Express.js, and MongoDB.

## 🚀 Features

* User Registration & Login
* JWT Authentication
* Product Listing & Details
* Shopping Cart
* Wishlist
* Checkout
* Order Placement
* MongoDB Database
* Responsive UI

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, CSS, Axios, React Router

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcrypt
